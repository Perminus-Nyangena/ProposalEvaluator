# Proposal Evaluator
 
The framework Technophiles Advisory uses to score fund and investment proposals consistently, so that decisions are repeatable and easy to explain.
 
## How it works
 
Each proposal is scored from 1 to 5 on weighted criteria. The weighted total ranks proposals, and a short written note records the reasoning behind every score.
 
## Criteria
 
* Strategic fit with the fund or investor mandate
* Market and demand evidence
* Financial viability and use of funds
* Team and delivery capacity
* Governance, risk and compliance
* Measurable impact
 
## In this repository
 
* scoring-template.csv: a sheet to score proposals
* rubric.md: what a 1, 3 and 5 look like for each criterion
* example-evaluation.md: a worked example with a fictional proposal
 
## Use it
 
Copy the template, score each criterion with a reason, and compare totals. Use the score to start the investment committee conversation, not to end it.
